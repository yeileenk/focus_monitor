# 집중도 모니터링 AI

웹캠 기반 실시간 집중도 측정 / 스터디 타이머 / 비대면 시험 감시 통합 시스템

## 설치 방법

```bash
# 1. 가상환경 생성 및 활성화 (권장)
python -m venv venv
source venv/bin/activate      # macOS / Linux
venv\Scripts\activate         # Windows

# 2. 의존성 설치
pip install -r requirements.txt
```

> **macOS**: `AppleGothic` / `Apple SD Gothic Neo` 폰트를 자동으로 인식합니다.  
> **Windows**: `malgun.ttf` 가 자동으로 인식됩니다.  
> **Linux**: `sudo apt install fonts-nanum` 으로 한글 폰트 설치 후 실행하세요.

## 실행 방법

### 일반 집중 모니터링 모드

```bash
python main.py
```

### 스터디 타이머 모드

```bash
python main.py --study
```

실행 시 터미널에 시간 입력 프롬프트가 표시됩니다. `MM:SS` 형식으로 공부 시간을 입력하세요.

```
========================================
  스터디 타이머 — 공부 시간 입력
  형식: MM:SS  (예: 25:00 = 25분)
  취소: Enter 키만 누르기 또는 Ctrl+C
========================================
  공부 시간 입력 > 25:00
```

타이머 종료 시 세션 리포트가 자동으로 생성·열립니다.

### 시험 감시 모드

```bash
python main.py --exam
```

시작 시 **5자세 필수 등록 촬영**이 진행됩니다 (아래 참고).

| 키 / 버튼 | 동작 |
|-----------|------|
| `q` | 종료 + 세션 리포트 자동 생성 |
| `s` | 중간 요약 콘솔 출력 |
| 화면 우하단 `종료` 버튼 | 마우스 클릭으로 종료 (등록 촬영 중에도 사용 가능) |

## 집중도 판단 기준

| 지표 | 방법 | 일반/스터디 모드 임계값 | 시험 모드 임계값 |
|------|------|------------------------|-----------------|
| 눈 개방도 (EAR) | Eye Aspect Ratio | < 0.25 × 20프레임 | < 0.25 × 10프레임 |
| 머리 자세 | solvePnP 각도 추정 | Yaw > ±30°, Pitch > ±25° | Yaw > ±12°, Pitch > ±15° |
| 시선 방향 (수평) | 홍채 가로 위치 비율 | < 0.35 또는 > 0.65 | < 0.38 또는 > 0.62 |
| 시선 방향 (수직) | 홍채 세로 위치 비율 | < 0.25 (위쪽) 또는 > 0.82 (아래쪽) | < 0.30 또는 > 0.78 |

> - 얼굴이 인식되지 않으면 EAR·머리·시선 전부 실패로 처리됩니다.  
> - 시험 모드에서 고개가 약간 돌아가도 시선이 화면에 고정된 경우 머리 자세 경고가 억제됩니다 (Yaw ≤ 30° 이내).

### 점수 가중치

| 지표 | 가중치 |
|------|--------|
| 눈 개방도 | 39% |
| 머리 자세 | 33% |
| 시선 방향 | 28% |

### 점수 구간

| 점수 | 상태 |
|------|------|
| 80 ~ 100 | 집중 중 |
| 60 ~ 79  | 보통 |
| 40 ~ 59  | 주의 |
| 0  ~ 39  | 경보 |

## 시험 감시 모드 기능

### 5자세 필수 등록 촬영

시험 모드 시작 시 아래 5자세를 순서대로 촬영합니다.  
**모자·선글라스·마스크·이어폰·전자기기가 감지되면 촬영이 차단**되고, 위반 물품 제거 후 다시 촬영합니다.  
등록 중 우하단 `종료` 버튼으로 언제든 취소할 수 있습니다.

| 단계 | 자세 | 조건 |
|------|------|------|
| 1/5 | 정면 | 얼굴 정면 바라보기 |
| 2/5 | 턱 들기 | Pitch < −8° (위쪽) |
| 3/5 | 고개 숙이기 | Pitch > 8° (아래쪽) |
| 4/5 | 왼쪽 귀 보여주기 | Yaw < −20° (왼쪽 회전) |
| 5/5 | 오른쪽 귀 보여주기 | Yaw > 20° (오른쪽 회전) |

각 자세는 약 0.7초(20프레임) 유지 시 자동 촬영됩니다.  
세션 종료 시 등록 사진 5장을 포즈 레이블과 함께 정리한 그리드 리포트(`logs/reg_report_*.png`)가 자동 생성·열립니다.

### 세션 중 인물 교체 감지

등록된 얼굴의 HSV 히스토그램을 기준으로 90프레임마다 현재 얼굴을 비교합니다.  
유사도가 0.25 미만이면 인물 교체 의심으로 판정하고 이벤트 로그 + 증거 사진을 저장합니다.

### 컨닝 패턴 자동 감지

| 패턴 | 감지 방법 | 판정 기준 |
|------|-----------|-----------|
| AI 탭 전환 의심 | HEAD_ISSUE + GAZE_ISSUE 동시 발생 | 1.5초 이상 지속 |
| 스마트폰 조회 의심 | 아래 고개(Pitch↑) 반복 | 15초 내 3회 이상 |
| 시선 이탈 (메모·옆 화면) | GAZE_ISSUE 단독 지속 | 2초 이상 지속 |
| 전자기기 감지 | YOLOv8 객체 감지 | cell phone / laptop / remote 등 |
| 이어폰 착용 의심 | YCrCb 적응형 피부색 모델 | 양쪽 귀 모두 비피부 균일 객체 감지 시 |

### 금지 착용물 감지

| 착용물 | 감지 방법 | 확정 프레임 |
|--------|-----------|------------|
| 모자 | ROI 경계선 분석 + YOLO 모델 (있을 때 우선) | 20프레임 연속 |
| 마스크 | 코~턱 영역 색상 균일도 분석 | 18프레임 연속 |
| 선글라스 | 눈 영역 밝기 분석 (피부 밝기의 65% 미만) | 18프레임 연속 |
| 인물 교체 | HSV 히스토그램 비교 (유사도 < 0.25) | 90프레임마다 1회 |

감지 시 화면 중앙에 빨간 경고창 표시 → 착용물 제거 시 자동 해제.

#### YOLO 모자 감지 옵션 (선택 사항)

`models/hat_detector.pt` 파일이 있으면 시험 모드에서 YOLO 기반 모자 감지를 우선 사용합니다 (신뢰도 임계값 0.42).  
모델 파일이 없거나 로드 실패 시 ROI 픽셀 분석 방식으로 자동 대체됩니다.

지원 클래스명: `cap`, `hat`, `helmet`, `hardhat` / `no_cap`, `no_hat`, `no_helmet` 등

### 이어폰 감지 원리

YCrCb 색공간에서 얼굴의 실제 피부색(코 끝·양쪽 볼 기준)을 샘플링해 적응형 피부 모델을 구성합니다.  
귀 주변 ROI 중앙 60% 영역에서 피부 범위(±3.2σ)를 벗어난 균일한 픽셀 비율이 기준을 초과하면 이어폰으로 판정합니다.  
흰 AirPods·검은 유선 이어폰 등 색상과 무관하게 감지되며, 양쪽 귀 모두 감지돼야 최종 경고가 발생합니다.

### 증거 사진 자동 저장

부정행위 의심 감지 시 `logs/evidence_세션ID/` 폴더에 자동 저장 (유형별 쿨다운 적용, 최대 60장).  
세션 종료 시 증거 사진을 4열 그리드로 배치한 리포트 PNG가 자동 생성·열립니다.

## 전자기기 감지

YOLOv8n 모델(COCO 데이터셋)을 사용해 웹캠 화면에서 실시간으로 전자기기를 탐지합니다.

**감지 대상**: `cell phone`, `laptop`, `remote`, `keyboard`, `mouse`

- 감지 시 화면에 빨간 바운딩 박스 + 라벨 표시
- 세션 요약에 감지 횟수 / 총 사용 시간 기록
- 첫 실행 시 YOLOv8n 모델 자동 다운로드 (~6MB)

## 세션 리포트

세션 종료 시 `logs/report_*.png`가 자동 생성·열립니다.

- 우상단에 세션 총 시간 (`MM:SS` 포맷) 표시
- 졸음·머리 이탈·시선 이탈 이벤트 수와 함께 **초 단위** 표기
- 집중도 시계열 그래프, 지표별 분포, 요약 통계 포함
- 시험 모드에서는 컨닝 이벤트 타임라인 추가
